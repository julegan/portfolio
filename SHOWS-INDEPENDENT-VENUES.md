## What explained the previous shortfall

- The prototype was maintained **manually**. No event ingestion, change-detection, or import queue is running.
- Prior passes systematically omitted events when a **genre label** could not be confidently assigned, even with a primary published date and show time. This iteration separates the basic event facts (publish) from optional music-style classifications (leave unclassified until evidenced).
- In small spaces, promotion lives in different places: No Fun has a highly detailed live event schedule, Twilight's venue calendar contains usable dates and times, Kenton Club publishes confirmed bills mostly **without performance start times**, High Limit Room's live site uses an iframe and external promoter listings, and independent promoters often use posters or Instagram.
- The calendar can remain editorially focused without excluding a whole independent venue when an event's exact genre is not yet known. Keep genre-less records discoverable in All Music, without inventing style tags.

## Thumbnail design decision

Each list event card and event detail now includes an abstract editorial thumbnail whose palette responds to known music styles or event categories; unclassified events use a neutral fallback. This ensures every event has a coherent non-photographic visual without fabricating a flyer, stealing artwork, or silently breaking when an event poster disappears.

True flyer art requires explicit organizer/artist permission or documented permitted use, source URL, credit, and `usageApproved:true`; see [ARTWORK.md](ARTWORK.md). No actual flyer images are incorporated in this batch. Thumbnails do not displace the compact mobile month grid.

## Future source-engineering recommendation

Build a **source registry and staging inbox** with per-venue acquisition method (`HTML`, ticketing, RSS/API, embedded calendar, promoter social, manual), fetch status, last-checked time, parsed event fields, field provenance, confidence, and a distinct human editorial approval status. The design should support venue-supplied dates with unknown show times as **undated-time leads for review**, rather than automatically publishing an invented hour. Deduplicate by venue/date/normalized lineup; flag cancellation, move and date conflicts; publish only approved entries and preserve the source trail. Avoid unapproved large-scale scraping and do not imply that a manually checked snapshot updates live.
